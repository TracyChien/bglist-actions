使用說明

這個網頁不會自己去打 Google Sheet 或 BGG 的 API——資料是由 repo 裡的 GitHub Actions 定期在 GitHub 自己的伺服器上抓好，寫成 data/games.json，網頁只讀這個檔案，完全不受你電腦或網路環境的限制影響。

想更新資料怎麼辦

到 repo 的 Actions 分頁，選左側的工作流程，按 Run workflow 手動觸發一次，等它跑完（通常 1～2 分鐘）刷新這個網頁即可。也設定了每天自動跑一次。

Google Sheet 欄位

BGGIDBoardGameGeek 遊戲編號。填了會自動帶出圖片、人數、年齡、時間、出版商、類別、簡介與擴充列表。
NAME你想顯示的遊戲名稱（必填）。
PLAYER / AGE / PLAYTIME / PUBLISHER / GAMETYPE手動填寫時會覆蓋自動帶出的資料。GAMETYPE 請填「派對遊戲／陣營遊戲／策略遊戲／心機遊戲／卡牌遊戲／兒童遊戲／家庭遊戲」其中之一。
IMGUR自訂圖片網址（任何圖床都可以），優先於 BGGID 抓到的圖。
OWN你擁有的擴充，用頓號「、」分開填 BGGID 或名稱關鍵字，畫面上該擴充就會打勾。
NOTE自訂備註，顯示在簡介下方。

類別分類參考

類別會依 BGG 的分類/機制標籤自動猜測，猜錯時直接在 GAMETYPE 欄手動指定即可。
